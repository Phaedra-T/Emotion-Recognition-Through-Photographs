#Emotion-Recognition-Through-Photographs
Application of classificatin technoques on the FER-2013 dataset.

The code explores and processes a dataset, visualizes the distribution of data and then performs various pre-trained classification methods in order to find out which one is optimal. The dataset - Facial Expression Recognition 2013 (FER-2013) is comprised of 32.298 48x48 photographs depocting 7 different human emotions. 

An assignment for the University of Macedonia course of Neural Networks.

Dataset credit to @msambare on kaggle
